# FruitBlend24 Business Dashboard

## Project Overview
Business analytics dashboard for a fruit beverage company.
The project analyzes sales performance, profitability, inventory planning,
waste management, and financial forecasting.

## Tools
- Python (Pandas)
- Power BI
- CSV Data Pipeline

## Data Workflow

1. Data Collection
- Raw data from Excel case dataset

2. Data Processing
- Data cleaning and transformation using Python (Pandas)
- Revenue, profit, waste, and inventory calculations

3. Dashboard Development
- Built interactive Power BI dashboard
- Created KPI monitoring and business insights

## Dashboard Pages

### 1. Executive Overview
- Revenue performance
- Profitability analysis
- Budget comparison
- Kitchen performance
- Waste overview

### 2. Operations Analysis
- Inventory planning
- Stock level recommendation
- Waste analysis
- Kitchen waste performance

### 3. Forecast & Financial Planning
- Revenue forecast
- Profit forecast
- Margin analysis
- Budget comparison

## Key Insights

- Bangkok kitchens show negative profitability due to high operating overhead.
- Pattaya kitchens generate positive profit performance.
- Mixed Berry Premium contributes the highest waste cost.
- Inventory optimization can reduce operational loss.

## Recommendations

- Review operating costs of Bangkok kitchens.
- Optimize inventory levels based on demand.
- Reduce waste from high-cost ingredients.
- Improve profitability through cost control strategies.
